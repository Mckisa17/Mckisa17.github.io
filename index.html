Book Tracker

2026 · Built with Claude Code · React, Flask

Private repository

Problem
Keeping a personal library and a daily reading habit up to date by hand is slow and easy to let slip.
What I built
An installable, mobile-first web app (React, Vite, Tailwind) backed by a Flask API running as Vercel serverless functions.
